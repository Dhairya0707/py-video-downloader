# Bulk Instagram Downloader

A simple Streamlit-based web application to fetch and download multiple Instagram Reels in bulk.

## Features
- Paste multiple Instagram Reel URLs at once.
- Fetches video metadata and previews.
- Direct download buttons for each video.

## Setup
1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```
